# ssh-protocol-network
# 🔐 SSH Configuration Project (Cisco Packet Tracer)

## 📖 Description

This project demonstrates how to configure **SSH (Secure Shell)** on a Cisco router to enable secure remote access instead of using insecure protocols like Telnet.

The network is built and simulated using Cisco Packet Tracer, including a router, switches, server, and multiple clients.

---

## 🧩 Topology

* 1 Router
* 2 Switches
* 1 Server
* 2 PCs
